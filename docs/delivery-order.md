# Delivery order

The task queue: Manifest's open work, in the order it is to be done. Each row is a task with its
[task ID](glossary.md#task-id), what it builds, when it is done, what must come first and the plan
that holds its design. Finished tasks are in [history/tasks.md](history/tasks.md); where Manifest
is going, by area, is the [roadmap](roadmap.md).

## How to use it

- **Work from the top.** The order is the default priority for one implementer. Rows whose
  prerequisites are independent may be worked at the same time
  ([D-051](decision-ledger.md#d-051)); who implements is in the [agent workflow](agent-workflow.md).
- **Dependencies.** "Must complete first" names the open tasks a row waits on, linked within this
  page, and the choices to settle before building. Finished prerequisites are left out. A
  dependency is complete when its checks and evidence are recorded, not when a patch or a stub
  exists; a useful stub is allowed under [D-056](decision-ledger.md#d-056).
- **Provision in Jettison before consuming.** A reusable capability the engine lacks is built in
  Jettison first, committed and pinned, and only then used here, as
  [Jettison's game integration](../../jettison/docs/game-integration.md#provisioning-a-capability)
  sets out. The pin is in [build and gates](build-and-gates.md). Engine work is in
  [Jettison's roadmap](../../jettison/docs/roadmap.md), its items numbered J01 onwards.
- **Every new authoritative mechanic** adds its state to the saves' inventory and its recovery
  tests in its own delivery ([persistence](persistence.md)).
- **Presentation** may progress once its own prerequisites are met; it must not block the native
  loop.
- **When a task is done**, its row moves to [history/tasks.md](history/tasks.md) with the date and
  a link to its record, the documents it changed are updated in the same commit, and the Order
  column is renumbered.

## Task IDs

| Prefix | Meaning |
| --- | --- |
| M | Maintenance before Stage 1 (finished) |
| H | Stage 1: the host (finished) |
| C | Stage 2: content (finished) |
| A | Stage 3: authority, one hosted world (finished) |
| N | The network: the server and remote clients (finished) |
| W | Stage 4: trading, travel and regional development |
| R | Stage 5: saves and recovery, the distribution (finished) |
| L | Later workstreams |
| T | The maintenance handoffs of 2026-11-16 (history only) |
| D-nnn | A decision in the [decision ledger](decision-ledger.md) |
| J | An item of [Jettison's roadmap](../../jettison/docs/roadmap.md) |

An ID never changes and is never reused; the Order column alone is renumbered. The
[stages](glossary.md#stage) are recorded in [history](history.md).
